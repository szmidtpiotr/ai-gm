# Witaj w vaulcie 👋

To jest przykładowa notatka-wrzutka. Tak działa inbox:

1. Masz pomysł → `Ctrl+N` → piszesz jedno zdanie → zapominasz o sprawie
2. Agent w sesji przegląda `00-inbox/`, dopytuje, porządkuje
3. Gdy pomysł dojrzeje → zmieniasz `status` na `do-wdrozenia` → agent bierze do roboty

Linki między notatkami robisz przez `[[nazwa notatki]]` — np. [[README]].
Graf powiązań: ikona 🕸 w lewym pasku.

Tę notatkę możesz skasować.
