# Dokumentacja projektu (`docs/`)

Ten katalog jest **wersjonowany w repozytorium** (GitHub), żeby można było przeglądać i edytować pliki z przeglądarki (także na telefonie) oraz współpracować z agentem na innym urządzeniu.

**Przeglądanie:** repozytorium na GitHubie → folder `docs/` → wybór podkatalogu fazy (np. `Phase_9B_Mechanics_Schema_Audit/`).

**Edycja w przeglądarce:** GitHub → plik → ikona ołówka (wymaga uprawnień do repo).
