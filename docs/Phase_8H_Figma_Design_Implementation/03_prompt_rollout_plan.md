# PROMPT 3 — Rollout plan redesignu (etapowy)

> Workflow: REV 1 (analiza + pytania) -> REV 2 (plan wdrożeniowy per fala).

---

## Cel

Przygotować etapowy plan wdrożenia redesignu z Figma tak, aby:
- zachować stabilność produktu,
- ograniczyć regresje,
- szybko dostarczać wartość ekran po ekranie.

---

## Kontekst

Na bazie promptów 1 i 2 mamy już readiness + kontrakty. Teraz układamy harmonogram i kryteria wejścia/wyjścia per fala.
W tym promptcie Cursor zarządza planem wdrożenia, a Figma dostarcza wykonawcze rewizje designu pod każdą falę.

---

## ⛔ PRZED IMPLEMENTACJĄ — pytania blokujące

1. Jak dzielimy redesign na fale (wave 1/2/3) i wg jakiej logiki?
2. Jakie KPI akceptacji fazy wdrożeniowej stosujemy (regresje, crash-free, UX)?
3. Jak wygląda rollback plan, jeśli fala powoduje regresję krytycznego flow?
4. Które ekrany migrujemy najpierw: game loop, combat, inventory, shop, admin?
5. Jak komunikujemy zmiany UI użytkownikom wewnętrznym/testerom?
6. Jakie testy automatyczne/manualne są wymagane przed przejściem do kolejnej fali?
